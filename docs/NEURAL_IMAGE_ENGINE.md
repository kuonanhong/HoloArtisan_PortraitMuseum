# 離線神經人像合成：交付狀態

本次已實作、下載真實預訓練權重，並以 CPU 實際生成蒙娜麗莎、戴珍珠耳環的少女的喜怒哀樂影像。這項功能在獨立的 **LivePortrait CPU 附件包** 中，和 GitHub Pages 靜態網站分開，避免把額外約 520 MB 的影像模型放入網站。

流程為：觀眾輸入文字／情緒／注視焦點 → 瀏覽器 Qwen 生成角色回覆 → 本機 LivePortrait 根據情緒、注視方向及回覆長度產生表情影像 → 網頁右側顯示選定觀眾的神經人像回應。神經模型具有學習式特徵變形與 SPADE 影像生成器；語意影像控制是有限的表情／頭部／眼神，不是任意文字生圖。文字內容會改變角色對話，回覆長度和問句狀態會影響嘴型；不把這種控制描述成完整視覺語言理解或音素唇語。

| 執行模式 | 真正執行的工作 | 設備 |
|---|---|---|
| 網頁離線文字 | Qwen 預訓練模型生成回覆 | 瀏覽器 CPU / WASM；依記憶體與效能而定 |
| 網頁即時人像 | Canvas 程序式眼神、嘴型、表情動畫 | 桌機與手機瀏覽器 |
| 可選神經影像 | LivePortrait 四個神經網路重新合成人像像素 | 同機 localhost Python CPU 服務 |

8 次離線測試以 Linux x86_64、PyTorch 2.6.0+cpu、4 執行緒執行，單張約 5.6–7.1 秒。不同裝置結果不同；手機端未測試 PyTorch。Windows/macOS 提供可移植程式與安裝步驟，未於本次環境實機驗證。

附件 `README.md` 列出安裝、啟動、HTTP 契約、影像大小與來源限制；`examples/validation.json` 與比較圖保留實測結果。固定官方模型與程式版本及每檔 SHA-256 已記錄。MIT 程式與模型授權保留；完全排除 InsightFace 非商業偵測權重，用人工 `faceBox` 取代。

此影像回應仍是應用層示範。一般平面螢幕沒有因此變成多人光學角度多工全像顯示器。
