這次以真實館藏為主角：左側是所選觀眾的表情與手動提問，中間保留原畫，右側顯示「該觀眾眼中的回應」。100 幅真實人物畫（50件CC0、50件公共領域）附來源、權利標示與本機圖片，不依賴遠端圖片熱連結。

先啟動完整互動

  1. 解壓 HoloArtisan_APR_FullPackage.zip。保留 index.html、js、assets、model、vendor 等資料夾的相對位置。
  2. 電腦有 Python 3 時，Windows 執行 Start_Windows.bat；macOS 執行 Start_macOS.command；Linux 執行 Start_Linux.sh。也可在資料夾執行 python3 tools/serve.py --open（Windows 可用 py -3）。
  3. 開啟 http://127.0.0.1:8000/，按「啟動離線生成模型」。Qwen 權重已包含在附件中；此時從本機磁碟讀取，不向雲端傳送提問。
  4. 選擇觀眾與喜、怒、哀、樂；點原畫設定注視位置，輸入一句話，按「讓畫作回應我」。每位觀眾保留獨立的情緒、目光與回應。
  5. 若要真正的神經網路人像合成，繼續下面的 LivePortrait 安裝。未連線引擎時，右側是明確標示的表情動畫，文字仍可由本機 Qwen 生成。

只雙擊 HTML 可以瀏覽畫作、移動、切換觀眾與排練；瀏覽器對 file:// 的模組與 Worker 限制使完整生成模型需要 HTTP/HTTPS。隨附的單檔 HTML 預覽內嵌館藏圖片；模型權重另在完整包內，沒有把 491 MB 權重塞進 HTML。

兩種生成模型，各做一件事

部分 技術 實際功能 執行位置

Qwen 是小型生成模型，回答品質和歷史知識有限；對話是當代互動創作，不是原作者的真實發言。LivePortrait 是人像神經合成，不是自由提示詞生成整幅新油畫；生成式文字決定回應，程式把表情／動作／視線對映到人像控制。畫作本身的背景、框幅與筆觸儘量保留。風景、多人物畫、側臉或很小的人臉不保證有理想人像合成效果，必要時用介面的臉部區域調整。

啟用真正的神經人像生成（電腦 CPU）

  1. 再解壓 HoloArtisan_NeuralPortrait_Addon.zip 到相同位置，讓 optional-image-engine 落在本專案資料夾內。
  2. 第一次安裝 Python 3.11 或 3.12。依 docs/NEURAL_IMAGE_ENGINE.md 安裝 CPU 版 PyTorch、NumPy、Pillow；這一步需要網路下載作業系統對應的套件。
  3. 到 optional-image-engine 執行 start.bat（Windows）或 sh start.sh（macOS/Linux），或 python server.py --preload。模型權重已在附件內，毋須再下載。
  4. 保持引擎視窗開著。在網頁展開「神經人像生成」，按「連線本機引擎」。預設 http://127.0.0.1:8766。
  5. 輸入提問並送出；Qwen 生成對話後，LivePortrait 合成右側人像。介面明確標記「LivePortrait 神經生成影像」。失敗時會顯示錯誤並保留動畫模式。

第一次套件安裝完成後，可斷開外部網路，本機文字與圖片推論皆不需雲端服務。Web 頁面自身不需要 npm、Node 或 Python 套件；Python 標準函式庫只負責供應本機靜態檔。完整跨系統 CPU 執行環境不是單一 HTML 能攜帶的內容，因此神經引擎用需求清單安裝對應平臺套件。

手機與多國語言

介面依瀏覽器的語言偏好選擇繁體中文、英文、日文、韓文或西班牙文，也能手動切換；不收集地理位置，不以 IP 推斷語言。館藏原文標題、作者名及來源保留原始資料，並非所有 100 個標題都有人工翻譯。

手機可開 GitHub Pages 網頁；先按頁尾「儲存到此瀏覽器，供離線使用」，待完整下載完成後，可斷開網路並重新開啟同一個網址。快取包含所有館藏、字型、WASM 與模型權重；未來更換程式或模型版本時，請先清除此網站的瀏覽器資料，再重新保存；瀏覽器清除網站資料或儲存空間不足時需重新儲存。請先在Wi-Fi環境下載約560MB。

Qwen 在支援 WebAssembly 的手機瀏覽器使用 CPU；約 491 MB 模型讀取及推論需要足夠 RAM，舊手機可能記憶體不足或反應較慢。這不是每臺手機已經實測的效能保證。神經影象合成則提供給本機電腦 CPU；不能把 Python 引擎直接放在 GitHub Pages 上執行。

手機若要連電腦同一個私人區域網路的網站，可使用 python3 tools/serve.py --lan，再用電腦區網 IP 開啟 8000 埠。神經引擎預設只接受本機連線，勿逕自將它公開到網際網路。HTTPS 網站存取本機 HTTP 的功能取決於瀏覽器本機網路政策；遇到阻擋，請使用同一臺電腦的 http://127.0.0.1:8000 完整版本。

本套件只收錄真實館藏的數位圖像；原畫區不使用 AI 仿作。完整清單、原始下載網址、典藏單位、逐件權利聲明、影像尺寸及 SHA-256，均保存在 data/artworks.json。js/artworks.js 是同一清單的瀏覽器版本，方便直接離線開啟 HTML。

  3. 同一畫作的不同解析度、不同照片或裁切副本不重複計數。清單依獨立原作計數；人物群像仍為一件作品。中文標題為本展示的便利用譯，原語／英文標題另行保留。

本地檔案做了哪些變更

原始圖像等比例縮小至最長邊不超過 1000 像素，並轉存 JPEG。保留整幅圖像與來源原有的畫框、橢圓邊界；不裁除簽名或浮水印、不用生成圖替代真實原作。來源影像若本來含邊框，該邊框也一併保留。瀏覽器的右側回應畫作為另外的互動衍生呈現，應與中間原作明確區分。

faceBox 是人工在原圖上估計的臉部範圍（正規化 x、y、w、h），用於示範表情回應；不是臉部辨識結果。群像指定一位主要人物，側臉、微小臉部與高度風格化畫作的動畫效果會與正面近距離肖像不同。

Holo-Artisan v2 離線生成模型說明

實際包含的模型

本附件已包含 Qwen2.5-0.5B-Instruct / Q4_K_M GGUF 的真實已訓練權重，並非只提供下載連結或預錄回答。來源為 Qwen 官方發布，Apache-2.0 授權；固定版本 9217f5db79a29953eb74d5343926648285ec7e67。原始權重 491,400,032 bytes，SHA-256：74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db。

此模型約 0.49B 參數，具中文、英語、日語、韓語、西班牙語等多語能力。最終版不用預設回答範例。先由模型自由生成畫中人物的對話，再由同一模型生成表情與動作JSON；兩段皆是真實推論。解碼只約束第一人稱起首：中文「我」、英文“I”、日文「私」、韓文「저」、西文“Yo”，沒有預先寫好的完整回答。

選用原因是 CPU 可執行、多語及開放授權之間的實用取捨；不宣稱它是所有任務中最好的模型。比分類器大的原因是本版真的要生成語句。0.5B 模型的推理、事實正確性、長對話及語言流暢度，均比大型模型有限；回應是虛構藝術對話，並非人物原話或經考證之藝術史。

如何工作

  1. 使用者明確按下載入後，頁面讀取同一網站／本地資料夾內的八個權重分段，每段不超過64 MiB；HTTPS與localhost 會逐段驗證SHA-256。
  2. wllama 3.8.1 在 Web Worker 中，透過 llama.cpp WebAssembly 執行模型。設定 n_gpu_layers: 0；標準GitHub Pages為 n_threads: 1，本地HTTP若提供COOP/COEP標頭，最多使用4個CPU執行緒，完全不使用GPU或雲端推論API。
  3. 每次將「作品名稱、手動輸入文字、觀眾情緒、注視焦點與座標、語言」送入本地模型，先生成第一人稱對話。第二次推論閱讀該對話與觀眾情緒，產生表情及動作JSON。程式合併成 text、emotion、gesture；情緒和動作由模型選擇，並非直接複製操作按鈕的值。
  4. 文字結果與動作參數傳给畫作呈現層。Qwen 是文字模型，不是圖片生成模型，也沒有直接看圖。 人物表情、視線與動作如何呈現，見主程式／圖像呈現文件。不得把 Canvas 動畫說成擴散模型生成的新照片。

模型接受文字和館藏中繼資料，沒有攝影機、麥克風或臉部識別。手動輸入文字在此瀏覽器分頁中處理；生成介面無任何外部推論端點。不要把此設計直接等同完整醫療隱私法規認證。

啟動與跨平台

  • GitHub Pages：完整資料夾保持相對路徑，HTTPS開啟，按「載入離線AI」。所有分段都能以普通Git檔案發布；不要使用無法由Pages直接供應的LFS指標替代權重。
  • 電腦離線：先解壓，執行 python tools/serve.py，再開 http://localhost:8000。模型、WASM、圖片都在本地，不需要互聯網。
  • 手機：可直接開GitHub Pages；真正離線使用前，必須先取得整包資產，或依主指南建立離線快取。僅開過首頁不代表491MB模型已下載。
  • 直接雙擊 file:// HTML 不支援模型載入：瀏覽器安全模型限制模組、Worker和讀檔。頁面會明確提示啟動本地HTTP，不會假裝AI已啟動。
  • 包含本地 Safari 相容 WASM，避開套件預設的CDN；舊版瀏覽器仍可能缺少WebAssembly SIMD／例外處理等功能。
  • 實際已測：桌面Chromium 138、禁用GPU、1與4個CPU執行緒、阻擋全部外部網路。Safari／iPhone與不同Android機型尚未在實機驗證，因此不保證所有手机皆可載入。

記憶體與速度

權重約469 MiB，但瀏覽器載入時還有 Blob、WASM、KV cache 和頁面圖像。建議使用可供瀏覽器使用至少1.5–2 GB記憶體的裝置；這是保守使用建議，不是最低需求認證。單執行緒生成可能需數十秒或更久，手機與Safari相容模式可能更慢。介面保留取消按鈕，移動、觀眾切換不應被 Worker 阻塞。此設計不提供「毫秒級即時生成」保證。

最終版實測：Chromium138、CPU四執行緒，三組完整「對話＋表情JSON」生成各為27.7、21.6、17.7秒。elapsedMs包含兩次推論。標準GitHub Pages通常只有單執行緒，可能明顯較慢；最終版的單執行緒時間請以主驗證報告為準。這些不是手機測速。

最終版語句品質、第一人稱、注視部位、原始生成文字／控制JSON、完整提示及程式SHA-256，在 tests/model-role-result.json。早期 model-browser-result.json 與 model-browser-threaded-result.json保留為執行器與外部網路阻擋測試紀錄，並已標示為舊提示／舊單次生成流程；不能將其時間當成最終版兩次推論流程的時間。不能以某一環境的測速保證所有设备相同。

小模型仍可能冗長、措辭不自然，或把提示中的座標說出來；測試也觀察到這種情況。最終三組測試都以畫中人物第一人稱回答並提及相關注視部位，但不代表任意問題都有可靠回答。未加入預錄回答替代模型輸出。

離線神經人像合成：交付狀態

本次已實作、下載真實預訓練權重，並以 CPU 實際生成蒙娜麗莎、戴珍珠耳環的少女的喜怒哀樂影像。這項功能在獨立的 LivePortrait CPU 附件包 中，和 GitHub Pages 靜態網站分開，避免把額外約 520 MB 的影像模型放入網站。

流程為：觀眾輸入文字／情緒／注視焦點 → 瀏覽器 Qwen 生成角色回覆 → 本機 LivePortrait 根據情緒、注視方向及回覆長度產生表情影像 → 網頁右側顯示選定觀眾的神經人像回應。神經模型具有學習式特徵變形與 SPADE 影像生成器；語意影像控制是有限的表情／頭部／眼神，不是任意文字生圖。文字內容會改變角色對話，回覆長度和問句狀態會影響嘴型；不把這種控制描述成完整視覺語言理解或音素唇語。

執行模式 真正執行的工作 設備
網頁離線文字 Qwen 預訓練模型生成回覆 瀏覽器 CPU / WASM；依記憶體與效能而定
網頁即時人像 Canvas 程序式眼神、嘴型、表情動畫 桌機與手機瀏覽器
可選神經影像 LivePortrait 四個神經網路重新合成人像像素 同機 localhost Python CPU 服務

8 次離線測試以 Linux x86_64、PyTorch 2.6.0+cpu、4 執行緒執行，單張約 5.6–7.1 秒。不同裝置結果不同；手機端未測試 PyTorch。Windows/macOS 提供可移植程式與安裝步驟，未於本次環境實機驗證。

附件 README.md 列出安裝、啟動、HTTP 契約、影像大小與來源限制；examples/validation.json 與比較圖保留實測結果。固定官方模型與程式版本及每檔 SHA-256 已記錄。MIT 程式與模型授權保留；完全排除 InsightFace 非商業偵測權重，用人工 faceBox 取代。

此影像回應仍是應用層示範。一般平面螢幕沒有因此變成多人光學角度多工全像顯示器。
